# OLA3D Calculator 1.0.0

First public release by **OLA3D**.

- CAD design and multi-material 3D printing price estimates.
- English / Hungarian installer and application.
- HUF / EUR / USD chosen during installation, with separate saved pricing profiles.
- Default CAD hourly rates: 5000 HUF, 13 EUR, 15 USD.
- Optional desktop shortcut; current-user installation without administrator rights.
- Self-contained Windows x64 installer, including the .NET runtime.

Download and run **OLA3D-Calculator-1.0.0-Setup-win-x64.exe**. Select the installation language and currency, then optionally enable the desktop shortcut. Prices are editable examples, not live exchange rates. The installer is not digitally signed.
